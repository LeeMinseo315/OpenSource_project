적록색맹을 위한 다양한 색각 보정 시스템 프로젝트입니다.

features
- 웹캠을 이용한 실시간 색각 보정
- 이미지 및 동영상 파일 업로드 기반 색각 보정(보정 강도 선택 가능)

algorithm reference
본 프로젝트의 색각 시뮬레이션 및 Daltonizaion 알고리즘은 기존 논문에 제안된 RGB-LMS 변환 기반 방법을 참고하여 구현하였습니다.
daltonize 오픈소스 프로젝트의 구조와 아이디어를 참고하였으나, 소스 코드를 직접 사용하거나 복사하지 않고 독립적으로 재구현하였습니다.
